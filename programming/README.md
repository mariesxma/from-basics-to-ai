# Programming

Learn how to give a computer instructions and solve problems with code.

## Available languages

- [Python](python/README.md) — start here; no previous programming experience required.

## Adding other languages

Each language gets its own folder here, such as `javascript/`, `java/`, or `rust/`, when its first lesson is ready. Shared mathematics, algorithms, computer science, and AI topics will have their own sections at the repository root.
