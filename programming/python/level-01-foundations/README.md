# Level 1 — Foundations

**Mission:** build and understand a complete terminal game.

[Enter Treasure Hunt](treasure-hunt/README.md): explore a small map, collect three treasures, survive hazards, return to camp, and play again.

You will combine variables, strings, lists, dictionaries, conditions, loops, functions, and user input. No previous programming experience is required; the project guide explains these concepts where they appear.

Complete the game's checklist to finish this level. Optional quests let you stretch your skills without expanding the core game too far.
